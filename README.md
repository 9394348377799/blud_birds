This is "blud birds", an angry birds knock off. This repository is coded within Python, utilizing both PyGame and PyMunk to visualize and make the game possible. All assets are made by me. 

## Physics concepts demonstrated

- Trajectory preview  -> projectile motion, gravity, launch angle
- Launch force/angle  -> initial velocity
- Block breaking      -> impulse, force thresholds
- Explosion radius    -> inverse-distance force falloff
- Pig mass vs wood    -> collision response between bodies
